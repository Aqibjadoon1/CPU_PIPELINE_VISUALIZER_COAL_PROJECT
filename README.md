# CPU Pipeline Visualizer COAL Project

Live demo: https://cpu-pipeline-visualizer-coal-project.netlify.app

This project is an interactive 8086 instruction pipeline visualizer built for Computer Organization and Assembly Language. It demonstrates how instructions move through fetch, decode, execute, memory, and write-back stages while showing register updates, ALU activity, flags, memory state, stalls, and RAW data hazards.

The source project lives in `coal proj/` and includes:

- 8086 assembly source and support files.
- A Node.js bridge/server for local simulation.
- A React + Vite + Tailwind UI.
- A browser-side simulator fallback for the public Netlify demo.
